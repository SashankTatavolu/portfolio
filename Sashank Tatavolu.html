SAVI

Semantic Annotation Validation Interface

A web-based platform for linguistic research, language data management and computational language processing. Projects are organised into chapters, sentences and segments, and annotation is collaborative. Published at DMR 2026 @ LREC-COLING.

  • Multiple user roles (administrators, annotators and reviewers), with task assignment, annotation, review and validation of linguistic data.
  • Visualization of linguistic structure, including dependency relationships and discourse-level information, to help researchers analyse complex language phenomena.
  • Structured data management, annotation interfaces and language processing in one workflow, supporting high-quality language resources for NLP and computational linguistics.

TagText

Document tagging platform

OCR turns a PDF into text but loses its structure: sections, paragraphs, titles, page numbers, headers and footers. TagText lets users upload a PDF and tag the extracted text with structural tags such as title, section, subsection and paragraph, so that structure is restored.

  • Led the migration from sentence-index tagging to a character-offset model, using browser selection APIs.
  • Sequence matching remaps tags automatically when the text is edited.
